# TD 离线授权：使用与维护

激活机制仅为防止滥用。本软件全部功能开源免费、非营利，不收取软件或激活码费用，仅供学习相关网络知识与机制，请在24小时内删除。技术授权有效期不是对真实打卡的许可，也不改变MIT许可。不要向冒充本项目维护者的收费渠道购买激活码。

## 普通用户

1. 在学生账号中心选择当前学生，再打开TD的“激活 / 续期”。
2. 点击“生成申请码”，自行复制给你确认身份的维护者。申请码只有安装/账号绑定摘要及随机挑战，没有明文学号、密码、照片或原始硬件标识，程序不自动发送。
3. 粘贴维护者免费提供的完整TDL1激活码。首次激活起一个自然月：例如1月31日08:00激活，平年2月28日08:00到期；时区为北京时间。
4. 同一码在本机核销后不能再次激活、延长有效期或转给其他账号。到期后生成新申请码再签发。重复输入不会重置首次激活时间。

未激活、到期、系统时间明显回退、绑定不匹配或授权存储损坏时，TD手动/自动请求均停止；已有记录、图片和当日预算保留。授权将结束前不足安全配对时间，不发起新入口；已经发出的请求不能撤回，未确认结果仍须按原规则核对。常规课程与博雅不要求此激活码。

授权仅作用于当前学生的 TD，常规课堂与博雅不受影响。未激活或已到期时先显示激活卡，不能进入 TD 页面；可返回常规课堂。账号既有图库、记录和预算不会因未激活而清空，激活后须核对设置并主动开启守护。

## 分发与签发边界

公开仓库和发行附件只提供客户端，不提供维护者签发工具、签发私钥、签发记录或密钥备份。激活码仅由维护者免费签发；客户端只含验签公钥，不能签发有效授权。请勿购买所谓付费激活码，也不要上传或公开自己的申请码、激活码和授权文件。

## 机制与实际边界

- Ed25519签名：客户端只有验签公钥；修改产品、学号/安装绑定摘要、挑战、月份等字段会使签名无效。
- 随机安装种子、操作系统机器标识摘要、当前学号共同绑定；请求不包含原始机器标识或明文学号。
- 本机核销、首次激活、到期时间及时间高水位以系统用户保护的加密数据保存，SQLite事务防止并发重复核销；到期计算为北京时间的一个自然月。运行期间结合单调时钟检查，允许少量正常校时误差。
- 授权查询没有远程激活服务器，不携带GitHub Token，不新增遥测；状态读取不发送学校请求。未开启TD时不额外轮询签名授权。
- **完全离线无法提供跨所有电脑共享的一次性核销库、可信联网时间或远程撤销。** 本机绑定、核销记录和时钟检查不能抵御具有本机控制权的人修改客户端、克隆/恢复整个系统及授权备份。不得宣传绝对不可破解、全局唯一核销或免风控。
- 客户端从配置同目录的TD私有目录读取授权；不要覆盖、公开或随普通发行包携带真实授权数据库。授权数据损坏时保留原文件并联系维护者，不自动重置或赠送新期限。

实现依据：[Cryptography Ed25519签名与验签](https://cryptography.io/en/46.0.4/hazmat/primitives/asymmetric/ed25519/)。申请/确认分离可参考[微软的安装ID与确认ID说明](https://support.microsoft.com/en-us/windows/activation/activate-windows-online-or-offline-using-installation-and-confirmation-id)，本项目不使用微软或微信的激活/支付协议。
