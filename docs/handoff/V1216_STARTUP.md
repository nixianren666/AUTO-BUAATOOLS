# v1.2.16：校徽描绘启动过渡

2026-10-17。用户先要求独立网页样稿，实际查看后明确回复“一遍过了，满意，直接应用”，因此已接入、编译并替换本地默认程序及便携版。未提交、推送或发布GitHub；已发布版本仍为1.2.7。用户最新额度规则改为五小时剩余5%时暂停并待重置恢复，旧45%规则不再代表当前要求。

## 交付行为

纯黑底中央校徽逐路径勾勒并填充，再从左向右描绘校名。界面尚未加载完成时清空重画；加载完成只排队收尾，不截断当前绘制。最后一轮完整后，校徽按真实侧栏图标的DOM位置缩放平移；校名逐渐高斯模糊至消失，黑幕渐透、主界面逐渐清晰。抵达后用实际校徽轮廓采样的小粒子散开，露出原应用图标。原界面布局、玻璃/流光美术及业务逻辑保持。

校徽2500ms、校名1800ms、完整停留380ms，循环清空240ms；归位1300ms、散开440ms。快速就绪通常只播放一轮；不会固定照搬样稿的第6秒模拟信号。就绪依据真实页面load后两个绘制帧，学校认证和课表网络操作继续按原逻辑异步进行，不以其成功作为揭幕条件。

图形来自用户指定的[THN-BUAA/BUAA-Logo](https://github.com/THN-BUAA/BUAA-Logo)。原始SVG与来源/ETag保存在`server/static/images`，仅含svg/g/path，无脚本、外链或事件；白色描绘副本内嵌HTML，启动无需另取校徽。上游没有独立LICENSE，学校标识权利不因代码MIT许可改变，README已有来源与非官方说明。轮廓描绘不是汉字书法笔顺。

## 实现与级联边界

- 新增独立`startup.js`/`startup.css`和临时展示DOM。未读取账号、学校数据、Cookie或本地偏好，不发网络请求，不创建周期轮询。完成后删除节点、清理RAF/计时器/监听器/全局引导对象，恢复滤镜、图标可见性、inert与焦点。原1%范围、独立更新查询、浮层互斥和所有既有UI模块保持。
- 原生窗口首帧背景设为黑色，和网页一致。可选网络字体不再阻塞首帧校徽绘制，下载后仍应用原字体。单文件解压及原生窗口创建前没有网页渲染环境；本交付不承诺覆盖操作系统启动进程之前的等待。
- 资源、SVG或动画API异常可撤幕降级；没有JS时不额外锁黑屏。独立16秒未加载保护防止无限等待；正常就绪后重新分配完整收尾时限，避免旧超时截断成功加载的最后一轮。就绪发生在清空阶段时会完成下一轮，不让半透明残片直接飞走。
- 隐藏时停帧，恢复已就绪窗口不保留陈旧遮罩；不会调用原生show或改变隐藏自启。尊重系统减少动态，兼容新旧媒体查询监听方式。必需免责声明仍未勾选、未接受，启动结束后恢复其焦点，不代替用户操作。
- 直接1.2.15的87份运行文件：74份字节一致、10份仅版本、3份为HTML启动层/窗口底色/README介绍与致谢，新增5份展示/图形文件。完整前端业务AST一致；原HTML事件与布局剔除精确启动插入及字体加载属性后相同。原生入口剔除版本和一个背景色参数后相同；另复核发布1.2.7精确提交`c379c018a66d882698051d01616d0700c3e46950`的19份后端业务文件，既有更新注册差异单列。学校API、认证、调度、重试、抢选、签到签退、统计均未改。
