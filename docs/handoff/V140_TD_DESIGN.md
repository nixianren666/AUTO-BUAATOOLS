# v1.4.0 TD 集成设计与实施边界

2026-10-19，用户明确授权把已分析的 AutoTD 接入本软件；此前“仅分析、未授权集成”已成为历史。此功能独立升版为 1.4.0，本轮未授权公开发布。直接基线 v1.3.9；常规、博雅、更新检查及当前玻璃美术保持。

## 用户视角

- PLATFORM 增加“自动 TD 守护”，继承现有卡片、下拉、动效和浮层。账号由学生账号中心统一选择，不增加第二套登录，不向 TD 发送密码。
- 学期/今日进度、活动日期与来源、任务阶段和待核验状态明确分开。未知学期次数显示“待核对”，不能显示为零，也不能将本地完成直接冒充官方体育成绩。
- 每账号本地图库：多选、拖入、缩略图、批量删除；入口出口各自随机，至少两图时避免连续重复。结果不确定不换图重发。在用图不能删除。
- 默认关闭；首次设置需确认本学期活动日期、本人参与及照片使用责任。历史春季公告不能当本学期规定。图库不是反识别保证。

## 工程视角

- 独立 TD TCP 客户端、SQLite 状态/图库、调度器及受现有 session/CSRF 保护的 API。无上游遥测、无查询次数时偷偷打卡的接口、无任意服务器地址。
- 发包前持久认领；跨线程/进程争抢由数据库串行化。每次重新核对账号、开关、实际时间和窗口；入口至出口严格小于七分钟。网络/保存失败不盲目重放。
- 本软件每日最多三轮，失败尝试也占用本地预算；只有一个状态机，不提供绕过它的独立手动发包入口。入口后停止时不偷偷发送出口；重开只在仍有效的配对窗口内继续，否则待核验。删除账号停止任务，保留私有资料供用户明确清理，不继续执行。不能据本地预算保证其他设备/线下提交未发生，界面明确禁止混用。
- 图片限量限大小，真实解码、EXIF 去除、重新编码，路径及身份不由文件名决定；私有存储不进入源码、截图或发布包。缩略图/原图走认证 API，禁缓存。
- 统计按活动日期隔离：仅真实返回计数标为“服务器返回”，人工核对标为“手动核对”，从不把刷新页面做成一次入口请求。

## 维护者视角

- 当前 TD 旧协议使用校园网原始 TCP，无可声称的传输加密；学校规则与照片最终审核由学校决定。本轮用严密合成 Mock，不发送真实 TD 请求或个人照片。
- TD 专属日志接入现有终端，脱离上游后台 PID/独立账号/遥测体系。短轮询仅查本地状态；隐藏页面停止 UI 轮询，业务守护仍独立。
