# v1.2.20：回退可见性能优化，保留隐藏暂停

2026-10-17。用户再次报告1.2.19的多个模块在启动、鼠标移动、点击和静置时持续闪烁，明确撤销可见状态的性能优化，要求恢复优化前版本。此前1.2.18/19的通过记录没有排除该回归，不能用它否认用户体验或宣称已证明所有闪烁根因。

## 当前决策

- 可见绘制以性能改动前的精确本地1.2.16快照为基线，删除后加的半分辨率宽光带缓冲、定时唤醒、点阵驻留休眠、有限NEW呼吸等可见优化。恢复原先流光、点阵和启动呈现，不继续叠加优化。
- 保留1.2.19已授权的博雅筛选作用域、空列表与课程结束时间修复。整个app.js除版本号外AST一致；学校请求、认证、签到签退、抢选、调度与重试保持。
- 仅在真正最小化/隐藏到托盘时停止Canvas绘制、CSS/WAAPI动效，并将隐藏界面的filter/backdrop-filter设为none；恢复后还原正常玻璃。后台学校任务继续，不承诺整个进程CPU/GPU为零。
- 不扫描遮挡/前台/窗口层级，不安装WinEvent或轮询，不写WebView.Visible，不隐藏正文或卡片。可见状态重复提示直接返回，不再反复写根元素class/dataset。
- 无其他安全优化或重构；用户已撤销旧交接中“不要回退1.2.16视觉”的限制。程序版本继续升为1.2.20，不伪装旧二进制，也不恢复旧配置。
