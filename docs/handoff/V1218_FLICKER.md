# v1.2.18：撤销遮挡停绘，移除界面显隐通路

2026-10-17，用户报告v1.2.17加载后持续闪烁，并明确要求取消窗口覆盖时停止渲染。此前通过的测试没有覆盖用户遇到的回归，不再把v1.2.17当作稳定交付。当前修复不改变学校业务、美术、排布或已有点阵/流光降载。

## 改动与适用边界

- 完整删除遮挡、窗口层级、前台窗口、其他进程窗口及DWM相关识别，不再安装WinEvent钩子或周期扫描窗口。
- 不再写入WebView控件的Visible属性，不再主动隐藏网页控件；删除整页 `content-visibility: hidden` 样式。
- Windows仅通过原生窗口的VisibleChanged与Resize事件读取真正的最小化/隐藏到托盘状态。状态在发送呈现提示前记录，重复事件与重入不会形成重复显隐循环；没有焦点事件触发的停绘。
- 最小化/托盘时暂停Canvas及装饰动效，恢复后继续；不暂停Python服务、学校请求、认证、签到、签退、抢选、统计或重试。
- 其他应用覆盖窗口时，软件不再自行识别遮挡并停绘。操作系统或浏览器自身的调度行为仍由平台决定，不能把它理解为新增的软件遮挡功能。

旧版确实存在“检测结果→隐藏原生网页控件→整页跳过显示”的高风险路径；本轮将这条通路删除，而非增加隐藏延迟。没有完整捕获用户旧版持续闪烁的逐帧波形，不能宣称已经证明所有闪烁只有一个根因。新版按直接行为断言和实际窗口观察验收，若有新的复现需保留现场继续定位。
