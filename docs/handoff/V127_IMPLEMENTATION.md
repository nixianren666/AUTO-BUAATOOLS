## 修复内容及连锁影响

常规签到使用官方时间和本人当日排课，认证/读取后与唯一POST前重验窗口。手动和后台共用锁与持久账本，最多三次实际发送；连接未建立不消耗发送预算，已发送但结果不明不得重放。

博雅严格解析容量、官方校历、完整分页、自主考勤地点/半径/教师窗口和考勤/考核状态。选课前比较普通课、已选博雅和持久在途预约。未知时间、容量、校历或不完整配置不授权自动选课；只按课程本体ID关联和防重。预约目标不会改学校考核规则。超时预约保持占位，不能因重启或时间经过解除不确定结果。

共享domain契约贯穿网络解析、后台actions/调度、API、前端状态与按钮、日志/通知。前端不推算“签到/结课即通过”，只展示官方能力；账号读写绑定代次，迟到旧响应不能覆盖新视图。任何字段修改均沿六层检查，反例对应见矩阵。

启用TLS及可信学校跳转白名单，默认回环管理，加入Host/Origin、私有会话和CSRF。旧固定密文只读，保存升级为DPAPI/系统凭据库或当前用户独占随机密钥加密；损坏文件/密钥不覆盖或转存明文。诊断不输出凭据和敏感URL。

后台按账号/课程隔离异常，停止、移除和认证维护使用代际及共享锁，关闭真正网络资源。日夜60秒同步、态势只显示首条。Windows配置级系统互斥锁/Unix文件锁与服务身份校验拒绝冲突实例。持久清理只删过期成功/明确失败，pending/uncertain保留。

保存失败撤回启用，暂停仍立即生效并说明重启风险；自启显示系统实际状态。修正托盘导致退出不结束、暗色目标输入、玻璃弹层Escape和手动ID误导文案。Windows卸载只清当前安装文件及其自启项，保留配置和无关文件。

发布改为手动四平台原生runner，空目录构建、编译后真实运行、安装/服务验收和产物清单，不自动写Release。修正Mac OpenSSL撞名、Linux图形依赖及Inno动态AppId设置。版本资源统一1.2.7，服务名称与更新固定标签一致。
