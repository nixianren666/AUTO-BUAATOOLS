# v1.2.19：博雅筛选作用域与空列表判断

2026-10-17。用户报告在全量课池开启“仅看可自动打卡”“仅看有名额”，再切到已选课后课程消失；并授权检查、修复同类业务细节。该授权针对本次筛选与归类问题，不重放历史发布或其他业务改造。

## 已确认的原因与修复

1. 课池两项快捷过滤没有按页隔离，已选课也被容量、自主考勤标记过滤。已选课程满员、缺少容量字段、需要现场考勤都不应因此消失。现在只在全量课池应用这两项条件。
2. 相邻的类别过滤存在同样问题：控件在已选页隐藏，但条件继续生效。现在类别也只影响课池。切回课池保留三个控件的选择，不靠重置开关掩盖问题。
3. 原空列表把“当前搜索/时间子集没有匹配”表述成“没有已选课程”。现在区分原始已选为空与筛选结果为空；缓存有记录时，不再因为筛选后为空就宣称数据完全未同步。原始数据确实为空且数据过期时，保留同步异常提示。
4. 归类曾先看签退截止（并回退到签到截止），再看课程结束时间，可能在签到窗口关闭时把进行中的课提前当历史。现在先尊重官方已结束标记、明确结束状态，再按课程结束时间；缺少结束时间时仅用签退截止作后备，绝不用签到截止替代课程结束。

保留的行为：已选页“未来及正在进行 / 历史 / 全部已选”只影响已选；搜索框始终可见，继续检索当前标签；标签数量代表原始总数，筛选不删数据。后台自动抢选仍强制要求完整线上自主考勤配置，界面过滤开关不改变后台偏好或这项业务限制。

| 调度与操作 | 抢选、签到、签退、退课、重试与后台同步未改；筛选不发写请求 |
| API与统计 | Python业务源码保持字节一致；已选与课池分别读取，统计仍按官方校历与考核事实计算 |

| 页面与美术 | HTML仅版本文字变化，CSS、图片、动效、启动和原生渲染模块完全不变；未恢复遮挡检测 |

同时覆盖切页来回、四种开关组合、隐藏类别、已选时间条件反向影响课池、搜索与清空、后台刷新后重绘、满员/未知容量/线下课程、账号切换、原始数组不被筛选修改。它是对上述交互链的针对性排查，不承诺全软件不存在其他业务缺陷。
