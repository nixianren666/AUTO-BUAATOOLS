# v1.4.11 客户端场景与远程管理复核

## 问题与改动

用户报告远程 Linux 首次声明不能加载。旧版在隔离的真实浏览器中已复现：取消原生管理密码弹窗后显示条款加载失败；已登录 cookie 的 bootstrap 仍401，而同一 cookie 能读到承诺。修复改用独立玻璃管理登录、有效 cookie 复用、单并发重连、错误密码/限流/离线回显，写请求过期不自动重放，保留 Host/Origin、HttpOnly、CSRF 边界。新增退出管理会话接口，不结束服务器任务。

服务器网页不再提供本机自启动修改入口，后端也拒绝此操作；桌面保留本机能力。容器缺少系统机器标识时使用显式配置的私有持久化安装标识，已有系统机器绑定不变，损坏文件不自动重建。密钥、图库、授权和配置仍需完整保存，容器安装标识不是硬件防克隆。

复查还修正无密码回环服务的退出行为：退出管理后清空当前页面，不通过刷新立即建立新会话。匿名管理登录在JSON解析前限制16KB正文（含分块传输）和12秒读取时限，密码输入另有类型/长度限制；不会把错误输入原文回显到错误报告。

开屏改为每个服务进程首次首页响应一次，所有浏览器/标签共享；预取不消耗，重开/刷新/账号与会话变化不重播。服务、容器或系统重启产生新进程后恢复一次，包括自启；中断不重播，减少动态与脚本失败仍可清理退出。原校徽校名、红字与缩放散开时间线保持。健康探测使用健康接口，避免首页探测提前消耗展示。

## 场景矩阵

| 场景 | 管理与状态 | 生命周期与持久化 | 本轮验证方式 |
|---|---|---|---|
| Windows 便携/安装 | 默认回环会话、CSRF、账号隔离、声明/TD入口 | DPAPI、目录权限、单例、托盘/退出、自启动 | 源码与成品浏览器；原生自动；Setup安装/卸载；实际窗口待补 |
| macOS arm64/x64 | 同一API与管理边界，原生窗口 | 钥匙串/私有文件、LaunchAgent、打包签名 | 各原生CI源码/成品/用户服务/DMG待新验；不等于真实用户设备或公证 |
| Linux 桌面 | 原生窗口，管理与账号交互 | 系统机器标识、私有凭据、用户服务 | Linux原生CI与成品、服务待新验 |
| Linux 无头/SSH隧道 | 回环免管理密码或显式密码；会话过期恢复 | 关闭浏览器不停止任务，部署工具管理自启 | 密码模式真实浏览器；禁止宿主自启写入 |
| Docker远程网页 | 显式密码+Host白名单，首次声明在登录后 | 整卷保存配置/凭据/TD数据/安装标识；容器重建 | 内网隔离真实容器浏览器及卷重建待新验 |
| 浏览器习惯 | 刷新、新标签、密码错/取消替代路径、离线与并发过期 | 启动批次共享；无 localStorage 仍可工作 | 新增10项真实 cookie 与 DOM 流程，原90项保持 |

## 当前证据与边界

本地第二轮342源码、90浏览器通过，Python隔离器0非回环尝试；新增10项真实密码管理流程通过。旧版失败与首轮新验证失败均保留在项目外：首轮发现 hidden 属性被样式覆盖，自启控件已改为同时使用既有 hidden 类并重验。新四平台、容器、成品、实际窗口、隐私与发行尚待最终证据，不能用v1.4.10结果替代。

本次不改变学校端点、参数、调度预算或签名格式。常规手动/自动共用预算与时窗；博雅保持仅自主线上签到课自动抢选、认证退避和人工验证码；TD保持配对/硬时段/每天最多3轮/不确定不重放/逐学生单次激活及续期窗口。已有边界回归覆盖这些业务；没有对真实学校服务执行写入，也没有真实账号全流程验收。当前秋季TD官方安排和纯只读次数接口仍未证实，不能承诺学校策略可用、免风控或全部无缺陷。
