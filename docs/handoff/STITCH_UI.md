## 用户追加的叠层毛玻璃

实现集中在 `design/stitch-workspace/layers.css`。大面板的背景放到 `::before` 上，40px模糊；内容是同级绘制层，内部控件使用18px模糊、1.2倍饱和度、低透明度底色与上亮下暗的细边。

原因：若把 `backdrop-filter` 直接放在包住所有控件的祖先上，它会形成 backdrop root，内层玻璃容易只模糊已经扁平的父层内容。独立背景面使内层保留可见的叠层质感。没有截取DOM、把整页截图用作纹理或循环生成 base64 图片。

页签选中态更亮；任务关闭态降低底色与亮边并保留明确的 `aria-pressed=false`；守护/暂停按钮同时改变文字与图标。不能为了所有按钮视觉完全一样而丢失交互状态。

## 级联影响与业务约束

- 新界面所有账号、课程、课表和日志均为合成数据，仅在内存里交互；没有持久化、学校请求、认证输入或真实抢选/打卡。CSP禁止连接请求与表单外发。
- 保留仅线上自主签到/签退课程的文案、课前十分钟窗口，以及“预约不等于签到/签退/考核通过”的区分；预览不模拟真实调度算法或安全判定。
- 演示账号分别保存开关、暂停恢复前的任务组合、目标、校区与已选课程。切换账号后课表也随账号切换，不复用前一个账号的固定安排。
- 本轮没有修改 `core`、调度器、`server/app.py`、正式前端或配置，没有编译/推送/更新 Release。合成数据 JS 不能直接替换正式 `app.js`；真正接入必须保持现有API字段、认证/CSRF、防重、异步账号隔离和错误反馈契约，并重新验证。

## 动态、隐私与降级

本地流光约20fps，画布尺寸上限1200px宽/1000px高，不按高DPI无限放大；仅保留小幅指针响应。源代码实现页面隐藏时停止RAF、系统减少动态默认静态和手动动态开关；本轮实测了手动停止、系统减少动态，不把静态阅读等同于完整后台性能实测。Canvas不可用时使用CSS静态背景；backdrop blur不支持时使用不透明度更高的底色。尚无多GPU/长时功耗基准。

截图来自隔离无用户扩展的浏览器与合成数据候选。没有提交用户浏览器截图、真实账号、凭据、学校状态或Google账户信息；候选没有外部资源加载与网络写入。
