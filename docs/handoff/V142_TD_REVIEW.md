## 实现与级联影响

1. td_policy 校验四日期、学期1–240天、活动在学期内、每日1–3轮、开放星期及停开日；与已同步官方校历不符则拒绝。td_client协议/设备映射/传输保持逐字一致。
2. td_scheduler 手动与自动进入同一状态机与持久预算，显式区分entry/exit。手动需先暂停自动；每次确认本人已到相应位置。并发入口只能认领一次；重复入口不会变成出口；出口等待3–4分钟且入口起七分钟截止，剩余时段不足430秒不发起入口。失败/不确定占预算且不重放，重启不返还次数。
3. td_routes 新增独立manual接口，沿用现有账号解析、会话/CSRF、账号锁；不新增密码传递。严格布尔/阶段/学号归属校验，不接受未知字段。
4. td.js 手动意图在请求前捕获，账号代际防旧响应串页，忙状态禁重，后端失败留在确认弹窗。照片组上传和两张角色不变，原生文件input隐藏，以双层玻璃选图卡触发。
5. HTML/CSS玻璃日历、开放安排表单和手动确认窗沿用既有材质；浮层管理只添加新模态ID，原常规/Boya函数及请求保持。图库改为整张details外框高度动画，从当前帧反转；隐藏、减少动态及账号/视图切换收尾，不设置永久渲染循环。
6. 原TD日志继续沿用，只在真实阶段接收/异常/用户操作记录；刷新、打开日历、折叠图库无学校写入。未知次数保持待核对，不做成功庆祝或补记。

## 三视角与风险矩阵

| 视角 / 情况 | 约束或处理 | 仍有边界 |
|---|---|---|
| 用户：不知道规则、周末/临时停开 | 星期不默认勾选，显式停开日，参考时段标注须本学期核对 | 没有实时官方停开推送，天气关闭需本人暂停 |
| 用户：自动暂时不可用 | 明确手动入口及配对出口、需到场确认、共用预算 | 手动不会绕过网络不可达或校方规则 |
| 工程：双击、重启、超时 | 账号锁、先持久认领、显式阶段、防重、不确定停发 | 学校是否接受不一定能由TCP响应完全证明 |
| 工程：改规则影响在途配对 | 在途/待核验禁止结构性改规则；可立即暂停 | 暂停后需按官方记录处理已有入口 |
| 工程：切换账号/旧响应 | 既有会话、明确username、代际及Abort、独立私有目录 | 本地管理员仍可访问本地数据 |
| 产品：学期次数未知 | 官方健康云链接+手动核对+来源和时间，不用打卡冒充查询 | 未完成自动只读次数查询，不把本地完成量当最终成绩 |
| 产品：照片一致性 | 一轮固定同组双图、用户确认本人同衣着妆容 | 不自动识别衣着，不承诺免审核；须本人实际参与 |
| TD传输/隐私 | 无上游遥测、去EXIF、私有图库、原协议不加密码 | 旧TD通道无TLS，图片发往学校，不能承诺防窃听 |
| Boya/常规连锁影响 | 核心文件和接口保持，隔离全回归覆盖原功能 | Mock与原生本地验收不等于真实学校全流程或各平台原生验证 |
