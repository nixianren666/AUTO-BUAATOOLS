## 接手方式

- 实现功能前，核对本次用户要求与这里的最新决策；旧助手的计划和断言不等于用户要求。
- 查一个历史问题时，用来源表中的会话 ID 和 `step_index` 定点读取，不必把一万多条工具记录全部装入上下文。

- 初次接管/上游研究与v1.3下架记录属于早期快照；随后已按用户授权完成v1.2.7业务修复、验收与发布。未执行真实学校写操作或操作用户远端部署服务器，现网仅受控认证/只读验证。
