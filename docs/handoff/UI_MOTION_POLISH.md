## 用户要求与实际改动

用户提供20秒录屏，要求背景持续流动、随鼠标移动，进一步打磨光线、圆角，并给成功操作增加简约的成就反馈。前提仍为不改变现有软件排布和业务逻辑。

已在原正式DOM中更新四份前端文件：`index.html`、`app.js`、`stitch-glass.css`、`stitch-ambient.js`。根目录默认EXE已重新编译替换，同级Git仓库四份源码已同步到本地工作树，未提交、未推送、未改Release，版本仍为1.2.7。原程序备份保存在本轮私有审查目录；用户配置哈希未变。

- **背景**：青紫色宽幅光带约24秒一轮持续形变，背景远光与近光以不同幅度响应鼠标，内容与按钮不跟随移动。近光设计最大位移约横向76px、纵向44px，并按实际绘图尺寸缩放，采用平滑缓动，不是生硬逐帧跟随。
- **光线**：保留上轮独立毛玻璃叠层，增加远处漫反射色场、近处宽幅柔光与较窄光芯。属于视觉近似，不是物理光线追踪、真实折射仿真，也没有直接复制Stitch视频素材。
- **控制**：透光度菜单新增“持续流光”“跟随鼠标”。默认跟随系统减少动态偏好，允许用户明确单独开启；偏好仅保存在本机浏览器存储。渲染分辨率上限1280×800，绘制上限24fps；页面不可见时停止，关闭动态和鼠标效果后不保持空转动画循环。
- **圆角**：外层卡片20px、内部模块12px、常规控件10px；短胶囊维持圆角胶囊。没有修改栅格、间距、卡片宽度或点击区域。
- **成功反馈**：确认成功的Toast为小绿勾加580ms一次柔光圈；常规课堂及博雅已签到/签退按钮使用一致的绿勾。既有服务端成功条件、待官方核验分支、失败条件、考勤与最终考核区分均保留。不会在每次轮询时重播庆祝动画。
- **降级**：缺少Canvas、初始化异常、绘制中途异常、脚本加载失败时不阻断账号与API初始化；没有Canvas滤镜时使用CSS柔光，避免生硬色带。Canvas滤镜兼容性依据[MDN说明](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter)，此分支已模拟缺失能力验证，不能当作Mac实机验证。

## 参考观察与事实边界

查看了用户录屏的私有采样帧：宽幅青紫光带会显著改变形状与位置，文字和面板稳定。稀疏帧不能证明录屏中每段运动都由鼠标引起，因此没有将其当作Stitch实时物理渲染的证据。此前现网页面检查确认Stitch使用20秒循环视频；本轮按用户明确要求另行实现背景视差。个人录屏与采样帧没有复制进项目或Git。
