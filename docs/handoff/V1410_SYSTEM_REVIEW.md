# v1.4.10 全链路审查与局部修复

## 范围与当前状态

本轮来自用户的全功能复盘请求，以及声明可复制、侧栏博雅进度和 TD Beta 标记的追加要求。以已交付的 1.4.9 为基线，不恢复 UU 远程闪烁诊断、软件渲染、降帧或遮挡检测。1.4.10 已完成本地交付，未发布，不把本地 Windows 候选当作全平台发行。

审查覆盖网络底座、后台调度、API、前端状态/布局、统计和日志。使用用户、开发者、维护者三个角度核对：用户看见的状态是否真实；实现能否在并发、重启、超时和切换账号时保持约束；维护者能否解释请求、保护隐私并诚实交付。不能保证“百分百模拟真人”“不会风控”或“没有任何问题”；不通过伪装访问痕迹、突破验证码或实际学校打卡来证明安全。

## 本轮确认并修复的问题

1. **博雅读接口绕过认证保护。** 1.4.9 的课池读取和显式刷新直接获取 token，没有走后台统一的 60 秒退避和人工验证码暂停。重现包括：连续读取产生多次认证、并行读取重复认证、验证码后刷新仍尝试认证、维护状态仍尝试认证。先加入五项回归，五项全部失败，保留 source-first 证据；再统一使用每账号可重入锁与调度器认证入口。已有效的会话直接复用，普通认证退避也生效；未认证且正在等待验证码时不自动提交密码。没有改变学校请求格式和写操作。
2. **声明正文不能拖选。** 页面继承的 `user-select:none` 阻碍了用户复制原文。仅为声明及承诺原文加 `user-select:text`，保留完整承诺、勾选和服务端同版校验；不添加复制按钮，不拦截粘贴。
3. **侧栏信息不一致。** 博雅 `NEW` 改为本学期分类达标进度，与主面板复用同一渲染计算：德育最多2、劳育最多2、美育最多1、安全健康最多1，总计6。超额类别不抵其他类别；不是已选门数、签到次数或预约目标。校历/统计未知为 `—/6`，切换/移除当前账号立即清理旧值。TD 标记改为 `Beta`。渲染不新增学校请求。

## AutoTD 与本软件的差异

2026-10-21 再次读取 GitHub / PyPI：AutoTD `open` 分支仍为 `a4c6e9b10867d970bf31d730b28673244e7cc433`，主要是说明；实际发行实现仍是 PyPI `autotd-buaa==0.1.15`。发行包摘要与前次审查包相同，复核了本地相同包中的客户端、调度和运行入口，而不是将 README 当实现。

| 原实现相关机制 | 本软件处理 | 原因 |
| --- | --- | --- |
| 入口/出口设备报文及校园地址 | 保留协议含义，增加严格帧/大小/超时及发包前核查 | 不能擅自改学校协议，也不能把服务端接收当成绩认可 |
| 参考开放时段与短时配对 | 参考三段时段，但必须核对当学期活动日期、星期和临时停开；保留7分钟硬截止 | 通用默认值不是当前学校公告 |
| 次数刷新使用打卡报文 | 不导入这条查询路径 | 查询不得改变学校记录；未证实纯只读入口时如实未知 |
| 自动调度、进出配对 | 共享持久预算与双门禁；不确定不重放；一轮固定一组双图 | 降低重复请求、跨日补发、并发和错图风险 |
| 原默认遥测和历史云端 | 不移植遥测或云端个人库 | 无业务必要，不上传明文标识与个人照片 |

## 官方策略与不可消除的限制

- 体育部[2025–2026第二学期通知](https://tyb.buaa.edu.cn/info/1019/1622.htm)明确每日最多3次、进出7分钟内、三段开放时间，并禁止作弊。这是春季通知，活动期不覆盖本次秋季日期。[现行制度目录](https://tyb.buaa.edu.cn/ggfw/gzzd.htm)尚未提供可核实的本学期完整 TD 日期/星期/临时关闭安排，不能自动延长一周或默认周末开放。
- 学期 TD 次数没有经本轮证实的纯只读接口。学校官方 APP/平台记录及最终审核是依据；本地完成配对不是官方有效次数。未伪造“已修复自动读取”。
- TD 原协议是校园内未加 TLS 的 TCP，不能宣称照片端到端加密。客户端的边界保护不能修复服务器身份校验、链路保密和到场真实性；不上传真实照片验证此风险。
- 纯离线许可不能保证全局即时撤销、跨系统快照绝对单次或绝对防破解。签发器不重建、不更换原钥；如需更强撤销与防回滚，需要另行明确在线架构和隐私取舍。
- 本轮没有真实学校账号端到端只读验收，没有真实学校签到/选课/TD提交，没有 Mac/Linux 原生和新 Setup/DMG 验收。模拟测试、Windows 原生自动与实际 Computer Use 分开记录；不能说“学校所有功能已100%恢复”。
