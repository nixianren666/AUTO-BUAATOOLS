## 修正与六层审查

旧版页面和后台读取超时均进入密码重认证，课表未知业务状态清除会话，已严格合成复现。新版区分明确过期与运输、HTTP、格式或未知响应。普通失败保留身份与缓存，标明未同步，不授权签到；真正 401、可信登录跳转或明确过期回复仍走既有认证锁和退避。

课堂会话建立失败不推断 SSO 过期。博雅 Cookie 换令牌的网络或未知错误不继续提交密码；仅明确 CAS 登录页需要认证时允许既有密码续期。普通错误网页与 HTTP403/503 不当成过期；验证码暂停仍要求人工。写入未知结果、防重预算和校历窗口不变。

网络底座保留有界只读备用端口、TLS 和可信跳转；调度失败不使用缓存签到，下一轮可恢复；API 保留缓存并在成功后消除 stale；前端保留 stale/offline 提示与按钮禁用；布局仅版本元数据；日志只记录异常类型，不写请求 URL、密码、Cookie 或 Token。不改用户 VPN/DNS/路由/防火墙，不强制 IPv4，不关闭 TLS。直连和学校 WebVPN 都可能受系统 TUN 影响。
