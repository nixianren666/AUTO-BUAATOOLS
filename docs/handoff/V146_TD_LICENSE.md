# v1.4.6 TD入口闪卡与逐账号单次授权

2026-10-21，本地交付完成，基线为本地1.4.5；没有推送或发布GitHub。默认程序、1.4.6便携、dist与独立签发器已替换，配置/图库/授权数据和原签发私钥保留。历史缺钥修复保留，不重生密钥。

## 用户要求与当前实现

- 只有TD需要授权，每个学生账号独立绑定；一人激活不开放其他学生的TD。未激活仍不能进入TD，只显示必需的激活卡片，可明确返回常规课堂。
- 激活码成功使用一次即永久核销，重复输入或续期不能复用；激活状态从首次激活起一个自然月。用户澄清的是成功使用后核销，本轮没有另设“未使用激活码签发后几天失效”。
- 仅到期前24小时内（含边界）或到期后，允许申请并使用新码续期。提前续期从原到期时刻顺延一个自然月，保留剩余时间；过期续期从本次激活时刻开始。续期完成后重新按新到期时刻限制，不能连续堆叠。

## 闪卡根因及修复

原入口先打开激活卡片，再异步查询授权，已激活账号也会短暂看到卡片。现在保持原页面并将TD导航标为忙，等待当前账号的新鲜只读结果：有效直接进入，无效/失败才显示卡片。不依赖旧缓存放行。查询中切换菜单或打开其他浮层会取消旧入口，过期响应不能重新打开TD。账号切换清除前一个学生的入口判断。

同一700ms受控授权响应路径，真实旧成品打开卡片1次、RAF可见采样165次；新成品打开0次、可见采样0次，最终均进入已激活TD。该数字是测试期间可见性采样数，不是FPS或性能指标；原始试探配置不完整的before.json保留，但不作为本对照。

## 六层影响核验与边界

`core/td_license.py`增加24小时窗口、有效授权记录校验和period_start；兼容无period_start的旧首次激活记录。签名格式TDR1/TDL1、公钥/私钥和账号绑定算法保持。SQLite事务内检查旧码核销、账号/安装/挑战、时间和续期窗口，再写入期限及used记录。旧激活记录不赠送新期限，损坏/回退仍拒绝。

常规/Boya底座客户端、学校端点参数、调度器/重试、防重、TD学校通道和日志实现均未修改；server授权路由继续调用同一授权对象，前端只增加入口等待和续期状态回显。本轮15份源码差异中9份仅版本元数据，其余为授权、TD前端、必要文案及对应测试。真实学校提交没有执行。

全离线只能在当前安装及受保护记录下核销，无法提供跨机器共享核销、可信联网时间或绝对防破解。续期记录增加period_start后，不应把1.4.5旧客户端覆盖回新授权数据上；后续版本需继续兼容该字段。未启用新的云端、遥测或学号上传。
